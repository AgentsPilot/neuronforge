BI System Design Notes

Key Design Principles

  • • Flexible Grouping: Users choose any primary dimension (Provider, Model, User, Agent, Activity, Execution)
  • • Category Columns: Every row shows breakdown by Creation/Execution/Memory/System
  • • Infinite Drill-Down: Click any row to drill deeper while maintaining context
  • • Context Chips: Show related dimensions at each level (how many users, agents, executions)
  • • Breadcrumb Trail: Always know where you are and navigate back easily

Data Requirements

  • • execution_id: Must be passed in ALL workflow LLM calls
  • • activity_type: Consistent classification (intent_contract, semantic_plan, llm_decision, etc.)
  • • agent_id: Link every call to its agent
  • • user_id: Always present (use SYSTEM_USER for platform calls)
  • • workflow_step: Track which step in the workflow made the call
